## 직접 실행한 대표 사례

| 단계 | 관찰 결과 | 에이전트의 기술 검토 판단 |
| --- | --- | --- |
| R1 | `FIT`, `HARD_REQUIREMENT_MATCH`, 검토 시점 `OPEN` | KR·기본설계·제품군 범위에서 확인된 22.9kV 요구를 24kV 합성 사양이 충족한다. 이 전압 조건만 기술 검토 가능하다. |
| R2 | `INSUFFICIENT_EVIDENCE`, `REQUIRED_PROJECT_FACT_MISSING` | 과거 숫자만으로 진행하지 않는다. 승인된 최신 단선결선도의 수전전압을 전기 설계 담당자에게 확인할 때까지 보류한다. |
| R3 | `NOT_FIT`, `HARD_REQUIREMENT_MISMATCH` | 확인된 33kV 요구를 24kV 후보가 충족하지 않는다. 현재 후보는 해당 조건의 적합 추천 대상에서 제외한다. |
| R1→R2 | 평가 무효화 `true`, 요구 상태·근거 참조 변경 | R1의 기술 평가를 그대로 이월할 수 없다. |
| R2→R3 | 평가 무효화 `true`, 요구 값·상태·근거 참조 변경 | 자료를 얻었다는 이유만으로 적합을 보장하지 않는다. R3 결과를 다시 확인한다. |

R2의 최소 추가 근거는 `REQUEST_ELECTRICAL_SINGLE_LINE`, 담당 역할은 `electrical_application_engineering`이다.
R3는 `VERIFIED_HARD_REQUIREMENT_MISMATCH`라는 기술 조건 문제이고, 부족한 근거 항목으로 표시하지 않는다.
실제 사람의 이전 결정을 입력하지 않아 `NO_PRIOR_HUMAN_DECISION`이며 대체 사람 판단은 `NOT_MADE`다.
이 표의 에이전트 판단은 구매·영업·입찰 등 최종 상업 판단이 아니다.
