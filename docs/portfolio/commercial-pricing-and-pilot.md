# 판매 가격과 유료 파일럿 제안

2026-10-29 기준. **산업재 기술영업팀의 요구사항·근거 검토 도구**로 판매한다는 가정이다.
소스코드 전체 양도나 독점 개발의 기업가치 산정은 아니다.

## 내가 제안할 가격

| 단계 | 제안 가격 | 제공 범위와 시작 조건 |
| --- | --- | --- |
| 현재 합성 시연·검토 작업 공간 | 무료 평가 | 로컬 사례로 적합성·근거·사람 판단의 구분을 체험. 운영 SaaS나 실제 제품 검증으로 판매하지 않는다. |
| 첫 유료 파일럿 | **팀당 150만원 / 2주** | 1팀·1제품군·최대 3건의 사전 합의된 검토 과제, 범위 설정·교육 2회·검토 패킷·측정 결과. 공급자 작업 20시간 상한을 제안한다. 자료 사용 권한과 성공 기준을 계약 전에 합의해야 한다. |
| 파일럿 이후 반복 사용 | **팀당 월 29만원부터** | 실제 재사용 의사·검토 가치·데이터/운영 조건이 확인된 경우에만 시험할 가격. 최초 제안 범위는 3사용자·월 10개 검토 패킷·지원 1시간. 현재 구현에 계정·과금·사용량 제한이 있다는 뜻은 아니다. |

가격은 **검증할 가설**이다. 아직 구매 의향, 유료 계약, 반복 사용, 업무시간 절감 자료가 없다.
가격을 받는 대상은 합의된 설정·교육·검토 지원과 결과물이다. 합성 데모 파일만 전달하고
150만원의 가치가 입증됐다고 주장해서는 안 된다. 세금·추가 개발·현장 방문·외부 데이터 비용은
견적에서 별도로 명시해야 하며 여기서 결제나 계약을 실행하지 않는다.

## 경쟁 서비스의 공개 가격

가격표의 통화 표기와 결제 단위를 보존했다. 환율로 원화 환산하거나 좌석당 가격과 팀 가격을
같은 것으로 비교하지 않았다. `$`만 표기된 페이지는 그 표기를 그대로 옮겼다.

| 서비스 | 확인한 가격 | 무엇을 사는가 / 비교 한계 |
| --- | --- | --- |
| [Clay](https://www.clay.com/pricing) | 월 결제 FAQ: Launch **$185/월부터**, Growth **$495/월부터** | 좌석 수 제한 없이 데이터 보강·GTM 워크플로를 제공한다. 자체 데이터/액션 사용량 과금이 있으며, 이 프로젝트의 기술 조건 검토와 같은 제품은 아니다. |
| [LinkedIn Sales Navigator](https://business.linkedin.com/sell/sales-navigator/compare-plans) | Core **US$119.99/사용자/월** 또는 **US$1,079.88/년** | 사람·회사 검색과 관계 탐색. 지역·세금·결제 조건에 따라 달라질 수 있다. 요구 사양 판정의 대체품으로 간주하지 않는다. |
| [AutoRFP.ai](https://autorfp.ai/pricing) | Scale **$899/월 환산, 연간 결제**; 24프로젝트/년 | 사용자 무제한, RFP 응답·지식·협업·SSO·연동 등 훨씬 넓은 운영 제품이다. 제시 금액의 연간 합계는 $10,788이다. |
| [Loopio](https://loopio.com/pricing/) | **개별 견적** | Foundations는 10좌석부터, 프로젝트/라이브러리 무제한. 현재 페이지에 공개 숫자가 없어 과거 인터넷 가격을 대신 넣지 않았다. |

참고 자료의 한계도 남긴다. [Apollo 공식 가격 페이지](https://www.apollo.io/pricing)의 검색 색인에는
Basic $49/좌석/월·Professional $79/좌석/월(연간 결제)이 있으나 현재 페이지 본문에서 카드가
표시되지 않아 주된 숫자 비교에서 제외했다. Clay의 월간 시작 가격은 명확하지만 Launch의
데이터 크레딧 수가 FAQ와 카드에서 다르다. [Responsive](https://www.responsive.io/pricing)는
시작 $10,000과 연간 플랫폼 요금·별도 라이선스/추가 서비스를 표시하지만, 해당 금액의 기간과
총 계약 비용이 불명확해 월/연 요금으로 환산하지 않았다.

이 비교에서 도출한 판단은 가격 우위나 기능 동등성이 아니다. 대량 연락처 데이터, 자동 발송,
기업 SSO 같은 폭넓은 약속 대신 **요구 → 적용 가능한 근거 → 예외/보류 → 다음 확인 → 사람의 판단**을
좁고 재현 가능하게 제공하는 것이 이 프로젝트의 판매 방향이다. 실제 정확성 우위는 측정하지 않았다.

## 150만원과 29만원의 산정 가정

파일럿은 공급자 작업 20시간 × 내부 시간 원가 5만원 = 100만원이라는 가정을 둔다.
150만원에 계약하면 남는 50만원은 간접비·재작업·이익을 감당할 여유다. 실제 투입이 30시간이면
같은 시간 원가만으로 150만원이 되므로, 무제한 수정이나 범위 없는 자료 정제를 포함하지 않는다.
이 시간 원가는 확인된 시장 단가나 실제 원가가 아니다.

월 29만원은 고객 가치로 다시 검증해야 한다. 현금 절감과 시간 절감은 다르므로,
`월 인정 가치 = 월 절감시간 × 고객이 합의한 시간당 비용 × 실제 활용 비율`로 보수적으로 본다.
시간당 5만원이라는 가정에서 필요한 월 절감시간은 다음과 같다.

| 시간 활용 가정 | 29만원 손익분기 | 요금의 3배 가치를 목표로 할 때 |
| --- | --- | --- |
| 절약한 시간의 100%를 유용한 일에 사용 | 5.8시간 | 17.4시간 |
| 절약한 시간의 50%를 유용한 일에 사용 | **11.6시간** | **34.8시간** |

3배는 이 제안의 판매 판단 기준이지 검증된 시장 법칙이 아니다. 임금이 실제로 줄거나 매출이
증가했다는 뜻도 아니다. 파일럿에서 가치가 확인되지 않으면 월 구독을 제안하지 않고,
범위·제품 또는 가격을 다시 정한다. 추가 수주율·매출 상승을 가격 근거로 꾸며 넣지 않는다.

## 파일럿에서 합의하고 측정할 것

1. 구매 담당자와 반복 업무를 특정하고, 검토 과제·자료 권한·기술 검증 책임자를 합의한다.
2. 문서 난이도가 비슷한 수작업/도구 사용 과제의 순서를 균형 있게 배정한다. 같은 정답을
   기억한 뒤 더 빨라진 결과만으로 효과를 주장하지 않는다.
3. 건별 작업 시간, 수정 시간, 잘못 통과시킨 필수 조건, 미해결 근거, 다시 사용할 의사를 기록한다.
   평균만 보지 말고 전체 사례 수와 원 기록, 실패 사례를 함께 본다.
4. 파일럿 성공의 제안 기준: 합의된 검토 패킷을 전부 전달하고, 출처 없이 VERIFIED로 승격한
   사례와 확인된 필수 불일치를 자동 통과시킨 사례가 0건이며, 담당자가 추적 가능한 근거와
   다음 확인 사항을 이해할 수 있어야 한다. 시간·가치 기준은 실제 기준 작업을 측정한 뒤 합의한다.
5. 새 작업 공간의 시간은 **자가 입력**이며 검증되지 않은 값이다. 에이전트 시뮬레이션을
   사람 참여로 집계하지 않으며 기존 정식 실험 기록에 자동 반영하지 않는다.

## 이번 구현과 판매 전 남은 일

현재 제공하는 [파일럿 검토 작업 공간](pilot-review-workspace.md)은 7개의 고정 합성 사례를
검토하고, 사례별 판단·이유·다음 과제·선택적 시간을 기록하며, JSON을 다시 열거나 Markdown
패킷을 내보내는 로컬 도구다. 입력한 주장으로 검증 상태를 바꾸거나 실제 제품/SKU를 비교하지 않는다.

실제 유료 과제를 시작하려면 승인된 자료·자료 권리·기술 의미 검증·정확한 납품 범위를 사람이
확정해야 한다. 호스팅 SaaS를 판매하려면 실제 인증·접근 제어·고객 데이터 처리·복구/운영 증거와
별도 배포 승인이 필요하다. 이 코드 작업은 그 승인을 대신하지 않는다.

`productionReady:false`, `NOT_PRODUCTION_EVIDENCE`, Issue #165 `HOLD`를 유지한다.
가격 협상, 결제, 고객 접촉, 실제 고객자료 처리, 운영 배포는 수행하지 않았다.
