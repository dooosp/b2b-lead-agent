# 검토 UX·파일럿 작업 공간 통합 기록

기준: `master@aef67fbea174a5db0b01d480a30f923a6b35d075`.
이 문서는 이전 로컬 검증 스냅샷과 이후 저장소 통합을 구분한다.
최종 커밋·PR·호스팅 CI 상태는 GitHub의 해당 기록을 따른다.

## 통합 범위

- 기존 리뷰 목록·상세 화면에서 저장 실패, 충돌, 새로고침 및 접근 거부 시 초안을 안전하게 처리한다.
- 포트폴리오의 비교·입력·인쇄 경험을 개선한다.
- 독립 합성 사례 7개를 검토하고, 판단·다음 행동·자가 입력 시간을 기록하며,
  JSON으로 다시 열고 Markdown으로 결과를 가져가는 오프라인 작업 공간을 추가한다.
- [가격·파일럿 제안](commercial-pricing-and-pilot.md)은 범위를 고정한 2주 용역 150만원과
  검증 이후 팀당 월 29만원이라는 가설이다. 실제 판매·구매 의향·효과를 입증한 가격이 아니다.

## 독립 리뷰에서 확인하고 수정한 사항

| 범위 | 발견한 문제 | 수정과 검증 |
| --- | --- | --- |
| 리뷰어 초안 | 목록 갱신 중 저장 응답이 이전 객체에만 반영되어 저장 완료로 잘못 표시 | 현재 리드를 다시 찾고 최신 버전과 비교. `worker/tests/manual-note-controller.test.mjs`의 캐시 교체·최신 버전 회귀 검증 |
| 접근 거부 | 앞서 시작한 목록 요청이 늦게 도착하면 보호된 입력이 다시 보일 수 있음 | 접근 세대가 바뀐 요청의 응답 폐기. `worker/e2e/manual-note-drafts.test.mjs`에서 거부 후 지연 응답 검증 |
| 기록 재가져오기 | compact 크기로 검증한 JSON을 pretty 형태로 내보내면 128KiB 한계를 넘을 수 있음 | 공통 compact serializer 사용. `worker/e2e/pilot-review.test.mjs`에서 130,615바이트 기록의 실제 다운로드·재가져오기 확인 |

위 수정 후 각 독립 리뷰는 PASS였다. 상세 검토 대화와 로컬 로그는 체크아웃에 포함하지 않는다.
검토 결과는 테스트가 다루는 로컬 계약의 근거이며 운영 승인이나 사람의 성과 측정이 아니다.

## 이전 검증 스냅샷

- [리뷰 UX 검증](review-experience-2026-10-29-verification.json): 당시 787개 통과.

- 각 JSON의 소스 지문·시각·검증 범위는 해당 시점의 값이다. 이후 패키지 명령 또는 보안
  의존성 수정으로 지문이 달라질 수 있으며, 이전 지문을 최신 값으로 덮어쓰지 않는다.
- `tmp/codex/`·`output/playwright/` 참조는 Git에 포함하지 않는 로컬 증거다.

## 최종 로컬 통합 검증

운영 의존성의 새 보안 권고를 확인해 [의존성 수정 기록](../security/2026-10-29-production-dependency-remediation.md)의
네 패키지를 갱신했다. 운영 의존성 감사는 높은 심각도 4개에서 0개로 바뀌었다.
이 결과는 `--omit=dev` 범위의 해당 시점 조회이며, 개발 전용 의존성 전체가 안전하다는 주장은 아니다.

Node 24.22.1에서 **815개 통과**: 루트 275 + Worker 단위 443 + 계약 30 + 브라우저 56 +
로컬 workerd 11. 실패·skip·TODO는 0개다. 집중 테스트나 중복 gate 실행은 합산하지 않았다.
이름·schema·보안 triage·enrichment·claims·spec-fit·lead replay·lead quality·Level 1과
현재 운영 의존성 감사까지 12개 추가 명령도 exit 0이다.
Nodemailer의 주요 버전 변경은 실제 설치된 공개 API와 로컬 stream transport로 확인했으며
SMTP·외부 메일 발송은 하지 않았다. 의존성 수정과 문서 휴대성 검토도 독립 PASS다.

이 수치는 커밋 전 로컬 검증 스냅샷이다. [통합 검증 JSON](integration-verification-2026-10-29.json)이
검증한 파일 지문을 보존하며, PR의 정확한 head에 대한 CI 결과는 별도로 확인한다.
독립 실행 평가판은 `index.html`, `workspace.json`, 사용 안내와 SHA-256 manifest로 구성한다.
ZIP을 푼 뒤 오프라인 브라우저에서 7개 사례와 JSON 기록 다운로드를 검사했다.
패키지와 상세 로그는 로컬 전달 자료이므로 저장소에 바이너리나 실행 로그를 추가하지 않는다.

## 운영 경계

PR과 브랜치 push의 저장소 워크플로는 검증을 실행한다. 실제 리드 생성·콜백·메일 발송은
별도의 `repository_dispatch` 워크플로이며 이번 통합에서 실행하지 않는다.
저장소 외부의 모든 연결이 없음을 보증하는 문서는 아니다.

`productionReady:false`, `NOT_PRODUCTION_EVIDENCE`, Issue #165 `HOLD`를 유지한다.
고객자료·실제 인증·원격 D1·실서비스 호출·배포·고객 접촉·과금은 수행하지 않는다.
실제 파일럿은 자료 사용 권한, 기술 검증 책임자, 납품 범위와 성공 기준을 사람이 확정해야 한다.
